King Pixel Europe is a modified pixel font made for this project by combining:
- Pixelify Sans, copyright 2021 The Pixelify Sans Project Authors, https://github.com/eifetx/Pixelify-Sans
- GNU Unifont 14.0.03 glyphs for missing European characters, copyright GNU Unifont contributors, https://ftp.gnu.org/gnu/unifont/unifont-14.0.03/

The combined font has a new family name and is distributed under the SIL Open Font License 1.1. See PixelifySans-OFL.txt and Unifont-OFL-1.1.txt in this directory for the license text. The unmodified source fonts are available at the URLs above.

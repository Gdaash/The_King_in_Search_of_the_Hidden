# Баланс боя

## Где редактировать

- На префабе юнита компонент `Combatant`: Base Health, Base Speed, Base Armor.
- `Assets/Resources/Combat/Weapons`: общие ассеты оружия. Damage — урон одного попадания, Interval — секунды между атаками, Range — дальность, Count — число снарядов/колец/ударов. Инспектор показывает базовый DPS.
- `Assets/Resources/Combat/Defense`: профили входящего урона. Значение 1 — обычный урон, 0.5 — половина, 1.5 — на 50% больше. Magical Multiplier действует на Magic, Fire, Ice и Electric.
- Ссылка Combat в `PortalTowerBalance → Weapons` ведёт к тому же ассету оружия. Баланс атаки не дублируется в каталоге апгрейдов.
- `GlobalStats` у этих бойцов хранит модификаторы улучшений. Старые базовые поля скрыты и не участвуют в их расчёте.

## Враги первого уровня

| Префаб | HP | Броня | Скорость | Защита |
|---|---:|---:|---:|---|
| Octopus | 20 | 0 | 2.2 | Обычная |
| OctopusRaider | 35 | 0 | 3 | Обычная |
| OctopusWarrior | 300 | 0 | 0.75 | Обычная |
| OctopusGuardian | 80 | 3 | 1 | Электричество ×1.5 |
| CursedKnight | 100 | 3 | 1.2 | Электричество ×1.5 |
| CursedMage | 60 | 0 | 1.5 | Физический ×1.25, все магические ×0.5 |

Урон попадания: `max(0, урон − броня) × множитель защиты`. Электричество пропускает вычитание брони. Броня действует отдельно на каждый снаряд, тик луча и попадание кольца; слабое попадание может нанести 0 урона.

На уровнях врагов здоровье и урон используют прежний прирост 10% за уровень. Броня растёт на 2.5% базового значения за уровень. Максимальный уровень — 50.

Базовый DPS каждого оружия — 20 против одной цели без защиты. Фактический урон зависит от попаданий, анимаций, расстояния и улучшений. Луч и кольца могут поражать несколько врагов, поэтому их суммарный урон по толпе выше.

В информации юнита добавлены броня, DPS и электрическая защита. Профили и оружие общие для вражеских и дружественных бойцов.

## Проверки

- `Tools → Validation → Combat Balance`: формула урона, профили, уровни, модификаторы, снаряды, UI и базовый DPS.
- `Tools → Validation → Portal Tower Roguelike`: оружие портала и выбор улучшений в Play Mode.
- `DefenseTowersValidation.Run()`: стрельба трёх защитных башен.

`Tools → Game Foundation → Combat → Install Combat Balance` предназначен для установки исходного баланса: повторный запуск перезапишет значения. Для обычной настройки редактируйте префабы и ассеты через инспектор.

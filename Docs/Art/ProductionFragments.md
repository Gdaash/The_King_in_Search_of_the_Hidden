# Частицы производства

Настроены префабы Forest 1–3, Stone 1–3, Iron Ore Mine, Magic Ore Mine, Chickens 1–3 и Boars 1–3.
На объекте рабочего Timer находится компонент **Production Fragments**.
Таймер раскрытия/исчезновения гекса эффекта не имеет.

В инспекторе компонента:

- **Timer** — прямая ссылка на таймер нужной стадии.
- **Fragments** — набор вырезанных спрайтов. Строительство шахт использует ConstructionWood, добыча — Iron или MagicOre.
- Для кур используется Feather, для кабанов — Hide. Частицы появляются на текущих позициях только видимых животных.
- **Dust Sprites**, **Dust Per Second** — бело-серые облачка и их плотность (по умолчанию 3/с). Пыль движется медленнее осколков и плавно растворяется. Значение 0 отключает пыль.
- **Surfaces** — прямые ссылки на спрайты стадий и заранее рассчитанные точки на непрозрачных пикселях. Выбираются только включённые спрайты.
- **Particles Per Second** — плотность, по умолчанию 5 частиц/с.
- **Lifetime**, **Upward Speed**, **Sideways Speed** — время жизни и скорость разлёта.
- **Capacity** — максимальное количество частиц на один эффект, по умолчанию 12.

Эффект работает только при активном таймере с оставшимся временем. Учитывает паузу и скорость игры. После окончания/отмены новые частицы не появляются, уже выпущенные затухают; при отключении объекта очищаются сразу. Созданные объекты используются повторно.

Спрайты: `Assets/Sprites/Effects/Production`. PPU 32, Point, без сжатия и mipmaps. Фрагменты зданий и животных — точные прямоугольные вырезки исходных PNG: координаты (left, top, right, bottom) записаны в `ProductionFragments.json`. Пиксели не перерисованы и не масштабированы. Dust1–3 — отдельные маленькие облачка 5–6 × 4 пикселя.

Команда **Tools → Production → Configure building fragments** повторно назначает настройки для этих четырнадцати префабов и пересчитывает точки после изменения спрайтов. Она восстанавливает исходные наборы фрагментов.

Проверка: `LogisticsCancellationAudit.RunProductionFragments()` запускает изолированный Play Mode; результаты находятся в `Temp/ProductionFragmentsAudit.txt`. Сцены редактора и сохранения восстанавливаются существующим тестовым механизмом проекта.

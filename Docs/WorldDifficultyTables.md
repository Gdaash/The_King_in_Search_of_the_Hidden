# Таблицы сложности World

## Выбор сложности

При входе в активный портал `DayCycleService` сохраняет его сложность от 1 до 5. На сцене World:

- сложность 1 всегда генерируется напрямую из списка `groups` префаба `HexManager`;
- сложности 2–5 выбирают наполнение из `HexDifficultyTable`;
- `AlarmSystem` выбирает пороги и состав волн из `AlarmDifficultyTable`.

Если World запущен без выбранного портала, используется сложность 1. Если сложность 2–5 ещё не заполнена, `HexManager` использует текущие группы своего префаба.

## Вкладка HexManager

| Столбец | Значение |
| --- | --- |
| difficulty | Сложность портала, 1–5 |
| group_id | Кольцо или группа гексов |
| prefab_path | Путь к префабу в Assets; пустое значение означает пустой гекс |
| content_id | Идентификатор контента для разблокировки улучшениями |
| mandatory | `1`, если строка обязательно входит в пул |
| auto_unlock | `1`, если гекс автоматически открывается |
| start_locked | `1`, если контент требует разблокировки |

Повторяйте строку, если один префаб должен встречаться несколько раз.

При экспорте строки сложности 1 всегда заново берутся из префаба `HexManager`, поэтому изменение количества групп, их ID и числа элементов сразу попадёт в экспорт. При импорте строки сложности 1 записываются обратно в этот префаб.

## Вкладка AlarmSpawner

| Столбец | Значение |
| --- | --- |
| difficulty | Сложность портала, 1–5 |
| threshold | Порядковый номер порога |
| alarm_value | Значение тревоги для включения порога |
| min_spawn_interval | Минимальная пауза между волнами |
| max_spawn_interval | Максимальная пауза между волнами |
| min_enemies | Минимум врагов в волне |
| max_enemies | Максимум врагов в волне |
| enemy_prefab_path | Путь к префабу врага |
| enemy_weight | Относительный вес выбора врага |

Для нескольких типов врагов на одном пороге повторяйте параметры порога и меняйте префаб с весом.

## Меню Unity

Команды находятся в `Tools > Таблицы > HexManager` и `Tools > Таблицы > Alarm Bar`. Для каждой таблицы доступны только экспорт в существующую вкладку Google Sheets и импорт из неё. Локальные CSV-файлы больше не используются.

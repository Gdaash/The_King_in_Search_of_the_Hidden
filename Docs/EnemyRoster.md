# Панель врагов World

## Настройка

- `Assets/Prefabs/UI/HUD/Enemy Roster.prefab` — панель в левом верхнем углу, под ресурсами.
- `Assets/Prefabs/UI/HUD/Enemy Roster Item.prefab` — строка типа врага: иконка, название, количество.
- Панель вложена в `World Screen HUD.prefab`; поле `alarm` связано с его Alarm Bar.
- Размеры, отступы, цвета, задержка тултипа и количество видимых строк настраиваются в инспекторе. При большом числе типов список прокручивается.
- Иконки отображаются в двойном размере импортированного спрайта. Для большого исходника орка есть отдельная копия с ограничением импорта до 32 px, PPU 32, Point и без сжатия; боевой исходник не изменён.

## Источник данных

`AlarmSystem.ConfiguredThresholds` уже содержит настройки текущей локации после `Awake`. Панель собирает уникальные префабы с положительным весом из всех порогов. Повтор одного типа в нескольких порогах не создаёт повторных строк. Будущие типы показывают 0, пока не появились.

Панель скрыта до первого настоящего спавна. Предупреждение и свет спаунера ещё не считаются врагом. После первой волны панель остаётся видимой, включая нулевые количества между волнами.

`AlarmSystem.RegisterSpawnedEnemy(prefab, instance)` привязывает тип к экземпляру. Метод вызывается из волн тревоги, `ObjectSpawner` и при появлении содержимого гекса. Фильтр пропускает только объекты с тегом Enemy1 и компонентом Health. Новые способы создания врагов должны вызывать этот же метод.

`AlarmSpawnedEnemy` следит за событиями здоровья и жизненным циклом экземпляра. При нулевом HP счётчик уменьшается сразу, до окончания анимации смерти; повторные события смерти и отключения не уменьшают его второй раз. Удаление, отключение и повторное включение живого юнита также учитываются. Реестр принадлежит сцене, в сохранения не записывается.

## Тултип

Используется тот же `Unit Description Tooltip.prefab` и `Unit Description Card.prefab`, что у наших войск. Каталог `Assets/Resources/UI/Unit Details/Enemy Description Catalog.asset` хранит только описание и ссылки на префабы. Числа читаются из компонентов боевого префаба и GlobalStats, копий баланса нет.

Тултип группы показывает базовые характеристики типа, а не HP случайного раненого экземпляра. Флаг `isEnemy` отключает строки еды, приказов и восстановления у портала, а также подписи опыта наших воинов. Защита остаётся в общей строке, частота атак — в атаках/с.

Новый префаб из списка спауна автоматически получает строку и таблицу, даже если описания в каталоге ещё нет. Для собственного названия, перевода, описания и UI-иконки добавьте UnitDescriptionDefinition с этим префабом в каталог. Инструмент `Tools / Game Foundation / UI / Setup Enemy Roster` также добавляет недостающие описания из конфигураций, сохраняя существующие.

## Проверка

`EnemyRosterValidation` создаёт отдельную временную Play Mode сцену без менеджера ресурсов, часов сохранения и прогрессии игрока. Проверяет настоящую волну AlarmSystem, группировку, счётчики при смерти/удалении/отключении, вторичный спаун, повторное включение панели и тултип на паузе. После остановки `End()` удаляет временную сцену и восстанавливает прежнюю стартовую сцену Play Mode.

# Время добычи

Базовая длительность всегда хранится в компоненте `TimerController`, поле `Duration` префаба соответствующего этапа. На корне здания может быть отдельный короткий таймер появления — для добычи редактируйте дочерний `Timer`. У шахт есть отдельные этапы строительства и добычи.

`Stats` в таймере — необязательная ссылка только на модификаторы. Формула: `max(0.2, (Duration - bonusProductionSpeed) * ProductionTimeMultiplier)`. Множитель включает приобретённое исследование «Заточить топоры», если оно включено для этого GlobalStats. Базового времени в GlobalStats больше нет.

При переносе Forest 1–3, Chickens 1–3 и Boars 1–3 получили Duration = 15 с, сохранив прежнее базовое время. Камень и шахты уже использовали локальное Duration и сохранены без изменения времени.

Новые настройки применяются при начале следующего цикла. Пауза и возобновление сохраняют остаток уже начатого цикла. Скорость игры меняет ход отсчёта, не базовую длительность.

В инспекторе таймера показаны базовая длительность, длительность с улучшениями и (в Play Mode) фактическое время текущего цикла и остаток.

Проверка: Tools → Validation → Production Timing. Временная ячейка сохранения восстанавливается после выхода из Play Mode.

# Первая вылазка

В первой успешной отправке через портал содержимое выбирается при завершении открытия гекса, независимо от его координат:

1. Forest 1
2. Пусто
3. Chickens 2
4. Stone 1
5. Forest 2

Все последующие открытия в этой вылазке пустые. Начало таймера, пауза и отмена не расходуют очередь. Повторное завершение одного гекса не расходует следующий шаг.

Настройка: префаб `Assets/Prefabs/Managers/First Portal Run Spawn Order.prefab`, компонент **First Portal Run Spawn Order**, список **Buildings**. Первый элемент — первое завершённое открытие. Пустая ссылка означает пустой гекс. Прямая ссылка на этот префаб находится в **HexManager**. Меняйте порядок, добавляйте или удаляйте элементы прямо в инспекторе префаба.

## Волна и побег

До сбора ресурсов первого задания на шкале нет волн, враги по порогам не появляются, кнопка побега скрыта. Тревога продолжает накапливаться.

Когда выполнены требования `First Expedition`, на текущей отметке тревоги появляется одна активная волна с параметрами первого обычного порога. Получать награду для этого не требуется. Показывается стандартное уведомление об уровне опасности.

Через 1 секунду после завершения уведомления кнопка «Сбежать» появляется в центре экрана с масштабом 1,5, затем плавно перемещается в исходное положение и уменьшается до обычного размера. Во время вступительной анимации она не нажимается.

Настройки анимации и прямые ссылки на задание, тревогу и кнопку находятся в компоненте **First Portal Run Presentation** на корне префаба `World Screen HUD`.

Счётчик походов и признак первой вылазки сохраняются в выбранной ячейке. Возвращение в укрытие завершает особый режим. Со второго похода используется стандартная генерация. Сброс ячейки возвращает первую вылазку. Старые сохранения с уже выполненным походом продолжают обычную генерацию.

Проверка в редакторе: `FirstPortalRunValidation.Run()` — запускает Base → World → Base → World, проверяет содержимое и защищает исходное сохранение тестовой ячейки. Отчёт: `Temp/FirstPortalRunValidation.txt`.
